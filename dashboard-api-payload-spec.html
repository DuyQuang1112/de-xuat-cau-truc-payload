Đề Xuất Yêu Cầu Dữ Liệu & Payload Response (FE -> BE)

Tập trung mô tả dữ liệu cần lấy & Cấu trúc Payload Json mong muốn cho 3 Màn hình UI (BE tự đặt tên API/Route)

📊 1. Dữ Liệu Cho 4 Widget Thống Kê Tổng Quan (Ảnh 1)

Widget 1: BOT đang chạy

FE cần API đếm tổng số lượng BOT đang ở trạng thái hoạt động.

Structure Payload Mong Muốn:

{
  "success": true,
  "data": {
    "runningBots": 15
  }
}
Widget 2: Tài khoản kết nối

FE cần API trả về số lượng tài khoản thuế đã kết nối (có token) và tổng số tài khoản khai báo kết nối.

Structure Payload Mong Muốn:

{
  "success": true,
  "data": {
    "totalHasToken": 150,
    "totalDeclared": 250
  }
}
Widget 3: Tài khoản đăng ký sử dụng

FE cần API trả về tổng số lượng tài khoản người dùng đăng ký sử dụng.

Structure Payload Mong Muốn:

{
  "success": true,
  "data": {
    "totalRegistered": 100
  }
}
Widget 4: Hóa đơn không thỏa mãn điều kiện

FE cần API đếm số lượng hóa đơn bị đánh dấu không thỏa mãn điều kiện.

Structure Payload Mong Muốn:

{
  "success": true,
  "data": {
    "unqualifiedCount": 15
  }
}

📈 2. Dữ Liệu Cho Các Biểu Đồ Giám Sát Kỹ Thuật (Ảnh 2)

Các biểu đồ nhận bộ lọc từ Toolbar: Từ ngày (fromDate) đến ngày (toDate).

Biểu đồ 1 & 2: Số lượng hóa đơn thiếu Chi tiết / XML

FE cần API trả về danh sách số lượng hóa đơn bị thiếu Chi tiết (hoặc thiếu XML) theo từng ngày trong khoảng thời gian chọn, phân chia theo 2 trạng thái: Có token và Không có token.

Tham số truyền vào (Params):

Tham sốMô tảVí dụ
typeLoại asset thiếu: detail (Chi tiết) hoặc xml (XML)detail
fromDateNgày bắt đầu (Format YYYY-MM-DD)2024-01-01
toDateNgày kết thúc (Format YYYY-MM-DD)2024-01-07

Structure Payload Mong Muốn:

{
  "success": true,
  "data": [
    { "date": "01/01/2024", "type": "Có token", "value": 500 },
    { "date": "01/01/2024", "type": "Không có token", "value": 700 },
    { "date": "02/01/2024", "type": "Có token", "value": 480 },
    { "date": "02/01/2024", "type": "Không có token", "value": 670 }
  ]
}
Biểu đồ 3: Số lượng đầu phiếu hóa đơn đồng bộ

FE cần API thống kê số lượng đầu phiếu hóa đơn đồng bộ theo ngày, phân nhóm theo 4 trạng thái: Đồng bộ, Cần lấy, Không cần lấy, Đã lưu.

Tham số truyền vào (Params):

Tham sốMô tảVí dụ
fromDateNgày bắt đầu (YYYY-MM-DD)2024-01-01
toDateNgày kết thúc (YYYY-MM-DD)2024-01-07

Structure Payload Mong Muốn:

{
  "success": true,
  "data": [
    { "date": "01/01/2024", "status": "synced", "label": "Đồng bộ", "count": 1200 },
    { "date": "01/01/2024", "status": "pending", "label": "Cần lấy", "count": 480 },
    { "date": "01/01/2024", "status": "ignored", "label": "Không cần lấy", "count": 210 },
    { "date": "01/01/2024", "status": "saved", "label": "Đã lưu", "count": 550 }
  ]
}

📅 3. Dữ Liệu Cho Lịch Thống Kê & Lịch Sử Đồng Bộ (Ảnh 3)

Danh sách Tài khoản thuế

FE cần API lấy danh sách Tài khoản thuế (hỗ trợ tìm kiếm theo MST/Tên) để hiển thị trong ô Chọn tài khoản.

Tham số truyền vào (Params):

Tham sốMô tả
keywordTừ khóa tìm kiếm (MST hoặc Tên công ty)
page / limitPhân trang (mặc định page=1, limit=20)

Structure Payload Mong Muốn:

{
  "success": true,
  "data": [
    {
      "id": "69d9c8ad9e8b75f3f9581aaf",
      "taxCode": "3700763669",
      "companyName": "CÔNG TY TNHH RICH PRODUCTS VIỆT NAM"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 250,
    "totalPages": 13,
    "hasNextPage": true,
    "hasPrevPage": false
  }
}
Thống kê Số lượng Hóa đơn theo Tháng (Giao diện Lịch)

FE cần API trả về tổng số lượng đầu phiếu trong tháng và chi tiết số lượng hóa đơn theo ngày của 4 loại: HĐ mua vào, HĐ bán ra, HĐ mua vào máy tính tiền, HĐ bán ra máy tính tiền cho tài khoản thuế được chọn.

Tham số truyền vào (Params):

Tham sốMô tảVí dụ
accountIdID của Tài khoản thuế chọn ở Header69d9c8ad...
monthTháng cần xem (Format YYYY-MM)2025-09

Structure Payload Mong Muốn:

{
  "success": true,
  "data": {
    "monthlyTotal": 160,
    "dailyStats": [
      {
        "date": "01/09/2025",
        "items": [
          { "type": "purchase", "label": "HĐ mua vào", "count": 10 },
          { "type": "sold", "label": "HĐ bán ra", "count": 10 },
          { "type": "purchase_pos", "label": "HĐ mua vào máy tính tiền", "count": 10 },
          { "type": "sold_pos", "label": "HĐ bán ra máy tính tiền", "count": 10 }
        ]
      }
    ]
  }
}
Lịch sử đồng bộ theo Ngày

FE cần API lấy danh sách các phiên đồng bộ khi chọn một ngày trên Lịch (mặc định ngày hiện tại).

Tham số truyền vào (Params):

Tham sốMô tảVí dụ
accountIdID tài khoản thuế69d9c8ad...
