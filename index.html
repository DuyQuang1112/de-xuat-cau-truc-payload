Đề Xuất Yêu Cầu Dữ Liệu & Payload Response (FE -> BE)

Tập trung mô tả dữ liệu cần lấy & Cấu trúc Payload Json mong muốn cho 3 Màn hình UI (BE tự đặt tên API/Route)

📊 1. Dữ Liệu Cho Widget Thống Kê Tổng Quan (Ảnh 1)

Widget tổng hợp: 4 chỉ số thống kê tổng quan

FE cần một API trả về đồng thời tổng số BOT đang chạy, tài khoản kết nối, tài khoản đăng ký sử dụng và hóa đơn không thỏa mãn điều kiện.

Structure Payload Mong Muốn:

{
  "success": true,
  "data": {
    "runningBots": 15,
    "totalHasToken": 150,
    "totalDeclared": 250,
    "totalRegistered": 100,
    "unqualifiedCount": 15
  }
}

📈 2. Dữ Liệu Cho Các Biểu Đồ Giám Sát Kỹ Thuật (Ảnh 2)

Các biểu đồ nhận bộ lọc từ Toolbar: Từ ngày (fromDate) đến ngày (toDate).

Biểu đồ 1 & 2: Số lượng hóa đơn thiếu Chi tiết / XML

FE cần một lần gọi API trả về đồng thời số lượng hóa đơn bị thiếu Chi tiết và thiếu XML theo từng ngày trong khoảng thời gian chọn. Mỗi nhóm gồm số lượng có token, không có token và tổng số hóa đơn thiếu của ngày đó.

Tham số truyền vào (Params):

Tham sốMô tảVí dụ
fromDateNgày bắt đầu (Format DD-MM-YYYY)01-01-2024
toDateNgày kết thúc (Format DD-MM-YYYY)07-01-2024

Structure Payload Mong Muốn:

{
  "success": true,
  "data": {
    "xml": [
      { "invoiceDate": "01-01-2024", "hasTokenValue": 500, "noTokenValue": 700, "total": 1200 },
      { "invoiceDate": "02-01-2024", "hasTokenValue": 480, "noTokenValue": 670, "total": 1150 }
    ],
    "detail": [
      { "invoiceDate": "01-01-2024", "hasTokenValue": 320, "noTokenValue": 410, "total": 730 },
      { "invoiceDate": "02-01-2024", "hasTokenValue": 300, "noTokenValue": 390, "total": 690 }
    ]
  }
}
Biểu đồ 3: Số lượng đầu phiếu hóa đơn đồng bộ

FE cần API thống kê số lượng đầu phiếu hóa đơn đồng bộ theo từng ngày. Mỗi ngày trả về số lượng theo 4 trạng thái và tổng số đầu phiếu.

Tham số truyền vào (Params):

Tham sốMô tảVí dụ
fromDateNgày bắt đầu (DD-MM-YYYY)01-01-2024
toDateNgày kết thúc (DD-MM-YYYY)07-01-2024

Structure Payload Mong Muốn:

{
  "success": true,
  "data": [
    {
      "invoiceDate": "01-01-2024",
      "syncedValue": 1200,
      "pendingValue": 480,
      "ignoredValue": 210,
      "savedValue": 550,
      "total": 2440
    }
  ]
}

📅 3. Dữ Liệu Cho Lịch Thống Kê & Lịch Sử Đồng Bộ (Ảnh 3)

Danh sách Tài khoản thuế

FE cần API lấy danh sách Tài khoản thuế (hỗ trợ tìm kiếm theo MST/Tên) để hiển thị trong ô Chọn tài khoản.

Tham sốMô tả
keywordTừ khóa tìm kiếm (MST hoặc Tên công ty)
page / limitPhân trang (mặc định page=1, limit=20)

Structure Payload Mong Muốn:

{

    "page": 1,
    "limit": 20,
    "total": 250,
    "totalPages": 13,
    "hasNextPage": true,
    "hasPrevPage": false

Thống kê Số lượng Hóa đơn theo Tháng (Giao diện Lịch)

FE cần API trả về tổng số lượng đầu phiếu trong tháng và chi tiết số lượng hóa đơn theo ngày của 4 loại: HĐ mua vào, HĐ bán ra, HĐ mua vào máy tính tiền, HĐ bán ra máy tính tiền cho tài khoản thuế được chọn.

🗄️ 4. Thiết Kế Bảng MongoDB — Widget

Collection đề xuất: dashboardwidgets Đề xuất — cần BE xác nhận

Lưu một document tổng hợp cho widget tổng quan. Các field thống kê được giữ phẳng để API có thể map trực tiếp sang data của payload FE.

Thiết kế field:

FieldKiểu MongoDBBắt buộcMô tả
_idObjectIdCóKhóa định danh document do MongoDB quản lý.
runningBotsInt32CóTổng số BOT đang chạy tại thời điểm cập nhật.
totalHasTokenInt32CóTổng số tài khoản thuế đã có token.
totalDeclaredInt32CóTổng số tài khoản thuế đã khai báo kết nối.
totalRegisteredInt32CóTổng số tài khoản người dùng đăng ký sử dụng.
unqualifiedCountInt32CóSố lượng hóa đơn bị đánh dấu không thỏa mãn điều kiện.
createdAtDateCóThời điểm document được tạo.
updatedAtDateCóThời điểm document được cập nhật gần nhất.

Document mẫu:

{
  "_id": ObjectId("66c000000000000000000001"),
  "runningBots": 15,
  "totalHasToken": 150,
  "totalDeclared": 250,
  "totalRegistered": 100,
  "unqualifiedCount": 15,
  "createdAt": ISODate("2026-08-19T08:00:00.000Z"),
  "updatedAt": ISODate("2026-08-19T08:00:00.000Z")
}

Quy tắc cập nhật:

  • Chỉ lưu một document tổng hợp nếu phạm vi chỉ cần số liệu hiện tại.
  • Khi cập nhật số liệu, cập nhật đồng thời các field thống kê và updatedAt.
  • API chỉ trả các field thống kê trong data; các field kỹ thuật như _id, createdAt và updatedAt không trả cho FE nếu không có nhu cầu.

🗄️ 5. Thiết Kế Bảng MongoDB — Hóa Đơn Thiếu Chi Tiết / XML

Collection đề xuất: dashboardmissingassets Đề xuất — cần BE xác nhận

Lưu kết quả aggregate dưới dạng document phẳng. Mỗi document đại diện cho một tổ hợp ngày hóa đơn, loại asset thiếu và trạng thái token; dữ liệu được tổng hợp từ invoiceraws và đối chiếu với externalaccounts.

Thiết kế document phẳng:

FieldKiểu MongoDBBắt buộcQuy tắc / mục đích
_idObjectIdCóĐịnh danh document thống kê.
invoiceDateDateCóNgày hóa đơn, chuẩn hóa theo múi giờ nghiệp vụ trước khi aggregate.
assetTypeStringCóChỉ nhận xml hoặc detail.
hasTokenBooleanCótrue nếu tài khoản có token; false nếu không có hoặc token rỗng.
valueInt32CóSố lượng hóa đơn thuộc cùng tổ hợp invoiceDate, assetType và hasToken.
createdAtDateCóThời điểm document thống kê được tạo.
updatedAtDateCóThời điểm số liệu được cập nhật gần nhất.

Document mẫu:

{
  "_id": ObjectId("66c000000000000000000030"),
  "invoiceDate": ISODate("2024-01-01T00:00:00.000Z"),
  "assetType": "xml",
  "hasToken": true,
  "value": 500,
  "createdAt": ISODate("2024-01-01T08:00:00.000Z"),
  "updatedAt": ISODate("2024-01-01T08:00:00.000Z")
}

Quy tắc tạo document:

Field đíchNguồn / điều kiện
invoiceDateLấy từ invoiceraws.data.tdlap.
assetType = "detail"Lọc invoiceraws.assets.detail.done != true.
assetType = "xml"Lọc invoiceraws.assets.xml.done != true.
hasTokenĐối chiếu invoiceraws.account với externalaccounts._id, sau đó kiểm tra token.
valueĐếm số invoiceraws._id theo invoiceDate + assetType + hasToken.

Một hóa đơn có thể được tính vào hai document khác nhau nếu đồng thời thiếu Chi tiết và XML, vì assetType được aggregate độc lập.

Index đề xuất:

db.dashboardmissingassets.createIndex(
  { "invoiceDate": 1, "assetType": 1, "hasToken": 1 },
  { "unique": true, "name": "ux_dashboardmissingassets_invoice_date_asset_token" }
)

Mapping sang payload FE:

{
  "success": true,
  "data": {
    "xml": [
      { "invoiceDate": "01-01-2024", "hasTokenValue": 500, "noTokenValue": 700, "total": 1200 }
    ],
    "detail": [
      { "invoiceDate": "01-01-2024", "hasTokenValue": 320, "noTokenValue": 410, "total": 730 }
    ]
  }
}
